Purchase Inventory Sales Flow

Ready-to-print functional flow document for testing team

End-to-End Functional Flow

Purchase Requisition -> RFQ / Vendor Quote -> Purchase Order -> Goods Receipt Note (GRN) -> Quality Check -> Putaway to Warehouse/Bin -> Inventory On-Hand Increased -> Inventory Available for Sale -> Sales Order / POS Sale -> Pick List -> Pack -> Dispatch / Invoice -> Inventory On-Hand Decreased -> Payment Collection -> Accounting Entries GRN -> Purchase Accounting Entry PO -> PO Status Tracking Sale -> Sales Status Tracking

Negative / Exception Paths

1. Purchase Order CreatedStart of the exception flow when stock is expected from vendor.
↓
2. Vendor Delivers?Decision point before any stock enters inventory.
No
PO Delayed / Follow-up
  • No stock increase
  • PO stays open
Yes
GRN Entry
  • Receipt recorded
  • Qty compared with PO
3. Qty Matches PO?Checks full, partial, or excess receipt.
↓
4. QC Pass?Quality check before putaway.
Partial / Excess
Partial GRN / Reject Extra Qty
  • Backorder open if partial
  • Extra quantity rejected
Pass
Putaway to Bin
  • Inventory on-hand increased
  • Ledger updated
5. Sales Request / POSSale can continue only if stock is available.
↓
6. Stock Available?Controls whether sale proceeds or is blocked.
No
Block Sale / Allow Backorder
  • No dispatch possible
  • Pending demand recorded
Yes
Pick + Pack + Dispatch
  • Invoice generated
  • Inventory decreases
7. Payment Received?Final sales closure decision.
↓
8. Customer Return?Return handling branch after sale.
Partial / No
Open Receivable / Credit Follow-up
  • Sale remains open
  • Collection follow-up required
Yes
Sales Return
  • Restock or scrap
  • Final exception handling
Final ChecksInventory ledger check and accounting entry check at the end of the flow.

Functional Test Checkpoints

  • Purchase side: requisition, PO approval, GRN posting, and inventory increase.
  • Inventory side: putaway location updates, available quantity, and status transitions.
  • Sales side: sale creation, pick/pack/dispatch, inventory deduction, invoice/payment.
  • Side effects: inventory ledger rows and accounting entries at each branch.
  • Negative flows: partial GRN, rejected QC, insufficient stock, partial/no payment, sales return.
